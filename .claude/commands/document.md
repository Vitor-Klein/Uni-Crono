# /document

Documente o que foi feito nesta sessão, roteando para o destino certo em `docs/`
(ver a seção `<documentation_sources>` do `CLAUDE.md`).

A pergunta é uma só: **isto descreve o sistema como ele é, ou o trabalho de
chegar lá?**

- **Como o sistema é** → `docs/architecture.md` ou `docs/conventions.md`. É
  estado: arquitetura, convenções, como rodar, como fazer deploy.
- **O trabalho de chegar lá** → a spec em `docs/specs/` (em especial "Decisões
  durante a implementação") ou o plano em `docs/plans/`. É processo.

Não escreva nos dois lugares. Se a resposta parecer "os dois", o texto está
misturando estado e processo — separe-o em duas peças antes de escrever.
